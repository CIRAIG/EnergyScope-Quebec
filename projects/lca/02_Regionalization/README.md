# Regionalized and prospective LCA in ESMs

This folder contains the code, data, and results supporting the paper:

> **Regionalized and prospective life-cycle assessment in energy system models: evaluating the effects on energy planning and environmental performance**
Matthieu Souttre, Arthur Chuat, Jonas Schnidrig, Loïc Fischer, Jamil Maj, Guillaume Majeau-Bettez, François Maréchal, Manuele Margni
*Preprint submitted to Renewable and Sustainable Energy Reviews, 2026*

## Overview

This work couples prospective and regionalized Life-Cycle Assessment (LCA) endogenously with the EnergyScope-Québec energy system model (ESM) to design net-zero energy pathways for the province of Québec by 2050 that avoid shifting environmental burden onto other regions or onto environmental issues other than climate change.

The workflow combines:
- **[premise](https://github.com/polca/premise)** — prospective background scenarios (IAM: IMAGE, SSP-RCP: SSP5-H and SSP2-L)
- **[regioinvent](https://github.com/CIRAIG/Regioinvent)** (via **[regiopremise](https://github.com/matthieu-str/Regiopremise)**) — inventory spatialization and background regionalization
- **[mescal](https://github.com/matthieu-str/mescal)** — harmonization and integration of LCA impact scores within the EnergyScope ESM
- **EnergyScope** (snapshot formulation) — the underlying energy system optimization model, implemented in AMPL and solved with Gurobi

Prospective-regionalization levels are compared (Default, Spatialized, Spatialized + Foreground regionalization, Spatialized + Background regionalization, Spatialized + Foreground + Background regionalization, each with or without IAM-based prospective background data), across two SSP-RCP scenarios (SSP5-H and SSP2-L run on IMAGE).

## Repository structure

```
02_Regionalization/
├── 01_Notebooks/     # Notebooks used to generate the regionalized/prospective LCA impact scores,
│                     # and process/plot results for the 2023 and 2050 snapshots
├── 02_AMPL_files/
│   ├── data/         # AMPL data files (.dat): LCIA scores for every technology/resource and
│   │                 # prospective-regionalization level
│   └── model/        # AMPL model files (.mod): LCA-related objectives and constraints
└── 03_Results/       # LCA impact scores, figures and tables generated from the notebooks in 01_Notebooks/
```

> **Note on data availability:** Raw LCA results and underlying ecoinvent-derived datasets in `03_Results/` are not included in this repository due to ecoinvent's licensing and confidentiality policy. All processing notebooks are provided so that results can be regenerated by users with a valid ecoinvent license. Aggregated, non-confidential numerical results underlying all figures are available in the article's Supplementary Information SI2.

- [AMPL](https://ampl.com/) with an academic or commercial license
- [Gurobi](https://www.gurobi.com/) solver

  - [`premise`](https://github.com/polca/premise) (v2.4.2)
  - [`regioinvent`](https://github.com/CIRAIG/Regioinvent) / [`regiopremise`](https://github.com/matthieu-str/Regiopremise) (v1.3)

  - `brightway2` / `bw2data`, `pandas`, `matplotlib`, `plotly`
- A licensed copy of the **ecoinvent database** (v3.10.1, cut-off system model)

## Reproducing the results

1. **Build LCI databases** ([`projects/lca/01_Setup/01_Create_LCI_database.ipynb`](https://github.com/CIRAIG/EnergyScope-Quebec/blob/main/projects/lca/01_Setup/01_Create_LCI_database.ipynb)): use `premise` to generate prospective ecoinvent databases (2023 and 2050, SSP5-H and SSP2-L scenarios), then apply `regiopremise` for spatialization and background regionalization.
2. **Generate LCIA scores** ([`projects/lca/02_Regionalization/01_Notebooks/00_Generate_LCA_indicators.ipynb`](https://github.com/CIRAIG/EnergyScope-Quebec/blob/main/projects/lca/02_Regionalization/01_Notebooks/00_Generate_LCA_indicators.ipynb)): use `mescal` to map EnergyScope technologies/resources to LCI datasets, remove double-counting, harmonize technological parameters, and compute normalized LCIA scores for each prospective-regionalization level. This will generate the raw .csv files in `03_Results/` and AMPL files in `02_AMPL_files/data/`.
3. **Run the ESM and generate plots** ([`projects/lca/02_Regionalization/01_Notebooks/01_Reference_2023.ipynb`](https://github.com/CIRAIG/EnergyScope-Quebec/blob/main/projects/lca/02_Regionalization/01_Notebooks/01_Reference_2023.ipynb), [`02_Min_TC_2050.ipynb`](https://github.com/CIRAIG/EnergyScope-Quebec/blob/main/projects/lca/02_Regionalization/01_Notebooks/02_Min_TC_2050.ipynb) and [`03_Sensitivity_analysis.ipynb`](https://github.com/CIRAIG/EnergyScope-Quebec/blob/main/projects/lca/02_Regionalization/01_Notebooks/03_Sensitivity_analysis.ipynb)): run the EnergyScope-Québec optimization problem for 2023, 2050, and for the sensitivity analysis, respectively. This will create the figures and tables in `03_Results/`.
